06 Use

Two machines.

1. Set up the hub

One machine stores the files. sinkd-srv keeps them under ~/sinkd-data. Leave this running.

hub
sinkd-srv
# OR if you want to sync a specific folder
sinkd-srv --sync-root /path/to/sync

2. Set up the client

On the other machine, pair once. The hub prints pair code 424242 for client … when this connects. Type those six digits at code from the server:. Then name the folder to watch.

client
sinkd pair 192.168.1.20
sinkd --anchor ~/Documents

If the hub is a service, that code line is in journalctl -u sinkd-srv -f.

3. Done

Sync is automatic while those two keep running. A save in ~/Documents shows up on the hub inside ~/sinkd-data, and on any other machine watching that folder as the same user. They stay in the terminals you started. Service files in the repo keep them running after you log out.
