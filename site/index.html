01 Private

Your machines. Your files.

  • One hub

    All connected machines store the files. Hub centralizes communication over TLS.

  • Just the change

    Only the changes are sent over the wire. libreflect is faster than rsync.

  • Two binaries

    Two commands: `sinkd-srv` and `sinkd`. One line to install

  • Both edits stay

    The hub is the source of truth. If you also edited, those files are set aside, not overwritten.

  • Pair once

    The hub prints a 6-digit code. Type it once on the other machine. Done.

03 Shape

One hub. The rest follow.

Run sinkd-srv on the machine that should hold the files. Run sinkd everywhere else, and name the folders to watch. A save is pushed. A file that shows up on the hub is pulled. A delete on one side becomes a delete on the other.

A share is one tree for every client. An anchor is one tree per user. Both live on the hub, under the directory you gave --sync-root.

04 Synchronize

One line. Two machines.

The script checks the checksum, then installs. Debian and Ubuntu get the package. Everyone else gets a tarball in /usr/local/bin. Set PREFIX to put it somewhere else. Download a specific build.

two machines
# hub
sinkd-srv --sync-root ~/sinkd-data

# the other machine, once the hub prints a 6-digit code
sinkd pair 192.168.1.20
sinkd --server 192.168.1.20 --anchor ~/Documents

The hub prints the pair code on stderr. Under systemd that is the journal, not the terminal: journalctl -u sinkd-srv -f
